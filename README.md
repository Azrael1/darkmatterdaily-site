# DarkMatterDaily Publisher Website

Public static website for DarkMatterDaily Publisher, ready for GitHub Pages.

## Files

- `index.html` - public landing page for DarkMatterDaily and DarkMatterDaily Publisher.
- `privacy.html` - Privacy Policy with TikTok OAuth data processing details.
- `terms.html` - Terms of Service.
- `callback.html` - TikTok OAuth callback page that forwards the complete query string to the local backend without displaying authorization parameters.
- `styles.css` - responsive site styling.

## GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository settings, enable GitHub Pages.
3. Select the branch and folder that contain these static files.

## Contact Email

Confirm the dedicated public contact email is consistent across the public HTML files before publishing.

## Privacy

No API keys, access tokens, private infrastructure details, or internal system secrets are included in this website.

## TikTok Review Notes

- TikTok OAuth is described as passwordless account authorization.
- Draft upload and Direct Post are documented as separate user actions.
- Direct Post requires explicit user confirmation and uses the selected privacy, interaction, and disclosure settings.
- Disconnect and data deletion request paths are documented in the public pages.
